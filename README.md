# 📚 Exam Study Assistant

A complete offline study website for managing your exam questions and answers. Everything works offline - no internet required!

## ✨ Features

- ✅ **Add Questions** - Create study questions with detailed answers
- 📁 **Organize by Subject** - Categorize your questions (Math, History, Biology, etc.)
- 🔍 **Search** - Find specific questions instantly
- 🎯 **Filter by Subject** - Focus on one topic at a time
- 👀 **Show/Hide Answers** - Test yourself before revealing answers
- 🗑️ **Manage Questions** - Delete individual questions or clear all
- 💾 **Offline Storage** - All data saved locally in your browser using localStorage
- 📱 **Responsive Design** - Works perfectly on mobile, tablet, and desktop

## 🚀 How to Use

1. **Download the files** from this repository
2. **Open `index.html`** in any web browser (Chrome, Firefox, Safari, Edge, etc.)
3. **Add your exam questions** using the form
4. **Organize by subject** for better studying
5. **Study offline** - all data is saved on your device!

## 📋 Files Included

- `index.html` - Main website structure and UI
- `style.css` - Modern, responsive styling
- `script.js` - All the functionality (add, delete, search, filter)

## 💡 Tips for Effective Studying

1. Add questions as you study
2. Use the "Show Answer" button to quiz yourself
3. Filter by subject to focus on one topic
4. Search to find related questions quickly
5. Delete questions once you've mastered them

## 🔒 Data Security

- All your data is stored **locally on your device**
- Nothing is sent to any server
- Your questions are private and secure
- Data persists even after closing the browser
